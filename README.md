## about me

I'm Ahron, a developer from the Philippines who builds full-stack apps with AI baked in. Mostly TypeScript and Python, Flutter when it needs to live on a phone. I like shipping small, useful things fast and iterating in public.

- 🚀 shipping **[prime-v2](https://github.com/rhon-dev/prime-v2)**, **[Kasaran](https://github.com/rhon-dev/Kasaran-App)** and **[Kumpas](https://github.com/rhon-dev/Kumpas)**
- 🌐 live: **[HirAIya](https://hir-a-iya.vercel.app)** · **[Shot or Spill](https://spill-or-shot.vercel.app)** · **[portfolio](https://portfolio-rhon-devs-projects.vercel.app)**
- 🧰 Next.js · React · Flutter · FastAPI · Prisma · PostgreSQL · MongoDB · LangChain · Claude · OpenAI
